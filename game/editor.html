地图编辑器 · 操作说明

视图

滚轮 缩放 · 右键 / 中键 / 空格+拖动 平移
F 回到出生点 · 0 全图 · G 网格
1–9 / Shift+1–9 切换图层

工具

B 画笔 · L 直线（Shift 吸附 0/45/90°）
R 矩形填充 · E 橡皮（改回草地）
I 吸管（Alt+点击也可）
C 碰撞开关（框选：设为不可走；Shift 框选：设为可走；再框一次同样区域撤销）
H 抬高台地层级（框选 +1；Shift −1）· K 把框选设为当前层级
S 拉直台阶（框住歪的台阶，自动规整成矩形，多余的台阶改回小径）
V 选择：拖建筑=移动，拖角点=缩放，拖红点=移动门，Delete 删除
T 树：点击种树，Shift 框选删除树

编辑

[ ] 笔刷大小 · , . 层级 −/+
Ctrl+Z 撤销 · Ctrl+Y / Ctrl+Shift+Z 重做
Ctrl+S 保存到游戏 · Ctrl+E 导出

常见用法

拉直台阶：S 工具框住整段台阶。
重画门口：选「门前地砖」，R 矩形填充门前那块；再用 V 拖门的红点贴到墙边。
加宽 / 拉平道路：选「道路」，L 直线按 Shift 画直，笔刷调宽；坡道用「清除坡道」刷掉，再 K 设为同一层级。

保存

「保存到游戏」写进本浏览器 localStorage；「发布到项目」需本机 npm run admin；「发布到 GitHub」需 fine-grained PAT。详见 docs/ADMIN_PUBLISH.md 与 docs/MAP_EDITOR.md。

管理员设置

令牌只存在本浏览器，不会写进地图文件或仓库。访客看不到发布按钮。

A · 本地管理员（npm run admin）

终端会打印一串令牌。粘贴到下方后，「发布到项目」会把地图写进本机 game/data/。

B · GitHub 在线发布

需要 fine-grained PAT，权限仅 Contents: Read and write，且只授权本仓库。步骤见 docs/ADMIN_PUBLISH.md。
