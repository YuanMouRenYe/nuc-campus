# 地图编辑器(v7.7)

`game/editor.html` 是一个离线运行的地图编辑器(不连网、不用 CDN,全部代码在 `game/js/editor.js` 和 `game/js/mapedit_core.js`)。它直接编辑游戏使用的三份数据:

| 数据 | 内容 |
|---|---|
| `game/data/ground.png` | 每 ¼ 格一个像素的地表类别(灰度值 = 类别编号) |
| `game/data/terrain.png` | RGB:R = 台地层级 + 1,G = 坡道位置,B 低 4 位 = 下坡方向(1 东 3 南 5 西 7 北) |
| `game/data/map.json` | 建筑(轮廓、门)、树、东西向台阶清单、出生点等;编辑器新增的碰撞开关保存在 `v77col` 字段 |

## 打开

```bash
cd game && python3 -m http.server 8090
```
浏览器打开 http://localhost:8090/editor.html(游戏里按 Tab 打开菜单,也能进入「地图编辑器」)。
URL 参数:`?pristine` 忽略本地修改、打开原图;`?at=x,y,z` 打开时定位到格坐标 (x, y)、缩放 z。

## 界面

- **顶栏**:工具、撤销 / 重做、保存到游戏、导出、导入、重置、检查、回到游戏、帮助(?)。
- **左栏 · 调色板**:道路 / 小径 / 广场 / 停车场(路面颜色统一)、门前地砖、四个方向的台阶与坡道、清除坡道、草地、山地草坡、花坛、台地挡墙、陡坎、水面、树林地面、裸土、建筑底面。
- **右栏**:图层开关(地面、层级着色、台阶 / 坡道方向、碰撞、建筑轮廓、门、树、路灯、电单车停车点、网格)、笔刷大小与层级、选中建筑的信息、检查结果。
- **底栏**:鼠标所在格坐标、地类、层级、缩放、未保存提示。

## 工具与快捷键

| 键 | 作用 |
|---|---|
| 滚轮 | 缩放;右键 / 中键 / 空格 + 拖动:平移;方向键:平移 |
| F / 0 / G | 回到出生点 / 全图 / 网格 |
| 1–9 | 切换图层 |
| B | 画笔 |
| L | 直线(按住 Shift 吸附到 0° / 45° / 90°) |
| R | 矩形填充 |
| E | 橡皮(改回草地并清除坡道) |
| I | 吸管(或 Alt + 点击) |
| C | 碰撞开关:框选设为不可走;Shift 框选设为可走;再框一次同样区域即撤销 |
| H / K | 框选抬高层级 +1(Shift −1)/ 把框选设为当前层级 |
| S | **拉直台阶**:框住一段歪的台阶,取覆盖率最高的行列组成规整矩形,矩形外多出的台阶改回小径,台阶方向取多数 |
| V | 选择:拖建筑 = 移动,拖角点 = 缩放,拖红点 = 移动门,Delete 删除 |
| T | 树:点击种树,Shift 框选删除 |
| [ ] / , . | 笔刷大小 / 层级 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做(最多 200 步) |
| Ctrl+S / Ctrl+E | 保存到游戏 / 导出 |

## 检查(validate)

「检查」会列出:
- 台阶两端在同一层级(没有连接不同高度);
- 门离建筑外墙超过 1.6 格;
- 可进入建筑的门从出生点走不到;
- 大片铺装从出生点走不到。

原图本来就有的问题(1 处门、约 30 处装饰台阶)会标为「原始数据已有」,不算新问题。

## 修改怎样进入游戏

### 方式一:只在本机浏览器试玩(不改文件)
点「保存到游戏」。修改以压缩后的 JSON 写进浏览器 localStorage(键 `nuc-campus-mapedit-v1`,约 0.8 MB)。同一浏览器、同一地址打开游戏时会自动读取,并在顶部提示「🗺 已载入地图编辑器的本地修改」。点「重置」或打开 `index.html?pristine` 可恢复原图。

注意:localStorage 按「协议 + 主机 + 端口」区分,换了端口就读不到。

### 方式二:正式写进 game/data(提交到仓库)
1. 在编辑器里点「导出」,得到 `nuc-campus-map-edit-时间.json`。
2. 在仓库根目录运行:
   ```bash
   node tools/apply_map_export.cjs 下载/nuc-campus-map-edit-xxxx.json        # 先加 --dry 试运行
   ```
   它会先跑一遍检查,再把旧的 `map.json`、`ground.png`、`terrain.png` 备份为 `*.bak-时间戳`,然后写入新文件。纯 Node,不需要安装任何依赖。
3. `npm test` 确认测试仍然通过,删掉 `.bak` 文件后提交。
4. 回到编辑器点「重置」清掉本地覆盖,以免和新数据重复叠加。

### ⚠ 不要再运行 build_map.py
`tools/build_map.py` 会从 OSM + 补充数据 **重新生成** `ground.png` / `terrain.png` / `map.json`,编辑器里做的所有修改都会被覆盖。如果确实需要重新生成(例如更新了 OSM 数据),请先保留编辑器导出的 JSON,生成后在编辑器里「导入」它并对照重做,或把修改改写到 `data/supplement_px.json` / `tools/layout_*.py` 里。

## 已知限制
- 编辑器只改地表、层级、碰撞、建筑、门和树;路灯由游戏按路网自动布置(`Core.placeLamps`),不能单独拖动。
- 高程图 `elev.png` 不在编辑范围内(只用于远景着色)。
- 新增建筑请用 V 选中已有建筑调整;编辑器不提供"新建建筑"(需要名字、楼层、室内等元数据)。
