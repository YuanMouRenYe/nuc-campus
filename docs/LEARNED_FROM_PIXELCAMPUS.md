# 从 PixelCampus 学到了什么（v7.8）

同事 [EXIST-D](https://github.com/EXIST-D) 的公开学习项目 [PixelCampus](https://github.com/EXIST-D/PixelCampus)（像素校园 · 河北工程大学新校区）是一个星露谷风格、多人在线的网页校园游戏（Phaser 3 + TypeScript + Vite）。本文件记录我们对它的研读结论，以及 v7.8 如何把其中**适合本项目**的想法落地。

## 许可结论（重要）

PixelCampus 根目录 `LICENSE` 写明：**不是开源软件，版权所有 © 2026 EXIST-D，保留所有权利**。允许个人学习、阅读源码、在笔记中少量引用并署名；**禁止**复制再发布、商用、部署为对公众开放的服务、删除署名、拿去训练对外发布的模型等。

因此本仓库（MIT）的处理是：

| 允许 | 不允许 |
|---|---|
| 阅读其 README / FEATURES / 架构文档，提炼 UX 与系统设计想法 | 复制、粘贴或改编其源代码 |
| 从零重写相似功能（沉浸、拍照、备份……） | 使用其程序化美术、音效、地图数据、字体以外的第三方素材包 |
| 在 CREDITS / 本文档中署名并链接仓库 | 把其仓库内容打进我们的发布包 |

v7.8 **没有**把 PixelCampus 的任何文件放进 `game/` 或 zip。

## PixelCampus 功能与架构摘要

- **地图**：704×544 格，1 格 = 2.5 m；蓝图 JSON（terrain / buildings / pois）→ `npm run assets` 编译成地面块与碰撞；另有本地地图编辑器写入 `manual.json`。
- **客户端**：Phaser 场景 + 大量 UI 面板；`src/shared/` 放联机协议与规则；程序化人物 / 猫 / 地面。
- **玩法（远多于本项目）**：多人聊天 / 好友 / 组队、共享单车、校园猫、钓鱼与图鉴、商店与经济、成就称号、宿舍、校园跑、精灵对战、管理员工具等。
- **UX 亮点**：沉浸模式（藏 HUD）、拍照模式（藏界面 + 保存带水印 PNG）、身份备份码、关于面板、地标传送、手机竖屏紧凑布局与横屏重排、门牌、小地图、文档纪律（FEATURES + CHANGELOG 同步）。
- **测试 / 工程**：vitest 数百项、CI、协作文档；联机服与部署不在公开仓库。

本项目（nuc-campus）已有且不必照搬的部分：真实地形台地、室内多层、作息 NPC、四季天气、任务小测、悬停介绍、地图编辑器、共享电单车、二龙山成就、手机摇杆、纯静态离线、MIT。

## 本版采纳（全部从零实现）

| 想法 | 我们怎么做 | 文件 |
|---|---|---|
| 沉浸模式 | `Z` / 菜单 / 右下角按钮；`body.immersive` 藏 HUD；偏好写入 localStorage | `js/v78.js`, `style.css` |
| 拍照模式 | `P` 进入；WASD 平移相机；Enter 保存 PNG；右下角本游戏水印「中北大学 · 像素校园漫步」 | `js/v78.js`, `js/v78core.js` |
| 存档备份 | 导出 / 导入 JSON（进度 + 成就 + 地图编辑覆盖 + 偏好），格式 `nuc-campus-backup` | `js/v78core.js` |
| 关于面板 | 版本、MIT、作者；说明 PixelCampus 仅作灵感且未复制代码 | 菜单「关于」 |
| 地标传送清单 | `Y` 打开 12 个常用点（主楼、图书馆、食堂、二龙山……），冷却 3 秒；骑车中不可传 | `V78Core.LANDMARKS` |
| 门口名牌 | 靠近有门的建筑时，门上方画木质小牌（程序绘制） | `V78.sprites` / `paint` |
| 竖屏紧凑 | `body.compact`：窄屏竖屏缩小顶栏 / 小地图 / 任务卡 | `style.css` |
| 文档 | 本文 + README / HOW_IT_WAS_MADE / CREDITS 更新 | `docs/` |

## 明确跳过（及原因）

| 内容 | 原因 |
|---|---|
| 多人联机 / 聊天 / 好友 / 宿舍 / 管理员 | 本项目定位纯单机离线；无服务器 |
| Phaser / Vite / TypeScript 重写 | 现有静态 Canvas 架构已满足离线与零构建；迁移成本高、收益低 |
| 钓鱼、商店、经济、精灵对战、校园猫 | 玩法体量大，且依赖其美术与数值；与「漫步校园」主线偏离 |
| 角色捏脸 / 手持物 / 表情动作 | 需要大量新像素资源；我们坚持程序绘制、不引入外部素材包 |
| 其地图编辑器 / 蓝图管线 | 我们 v7.7 已有 `editor.html` + `apply_map_export.cjs`，数据模型不同 |
| 共享单车实现 | v7.7 已有电单车（校规限速提示、停车点未核实） |
| 成就系统骨架 | v7.7 已有二龙山与骑车成就 |
| 复制其水印样式或「作者水印」逻辑 | 只用本游戏自己的署名文字 |
| 任何代码或 PNG/音频资源 | LICENSE 不允许 |
