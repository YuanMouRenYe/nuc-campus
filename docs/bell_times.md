# 中北大学 作息 / bell times used in the game (phase 4)

Checked 2026-11-01 against public pages on nuc.edu.cn. No single official 全校作息表 page was found,
so the times below are assembled from three public sources; evening times remain approximate.

| 节次 | 冬令时 (≈10月9日 – 5月5日) | 夏令时 (≈5月6日 – 10月8日) |
|---|---|---|
| 1–2 节 | 08:00–08:45, 08:55–09:40 | same |
| 3–4 节 | 10:10–10:55, 11:05–11:50 | same |
| 5–6 节 | 14:00–14:45, 14:55–15:40 | 14:30–15:15, 15:25–16:10 |
| 7–8 节 | 16:10–16:55, 17:05–17:50 | 16:40–17:25, 17:35–18:20 |
| 9–11 节 (晚) | ~19:00–21:30 (approximate, not sourced) | same |

In game the bell rings 上课 at the start and 下课 at the end of each 大节 (pair of periods).
The schedule follows the real date (override with `?bells=summer` / `?bells=winter`).

Sources
1. 国际教育学院, 2014-2015学年第二学期来华留学生课程表 — rows 8:00-8:45, 8:55-9:40, 10:10-10:55, 11:05-11:50,
   14:00-14:45, 14:55-15:40, 16:10-16:55, 17:05-17:50; note "劳动节以后按夏至时执行 / afternoon postponed half an hour after May Day".
   http://international.nuc.edu.cn/info/1148/1625.htm
2. 中北大学办公室, 关于2025年"五一"国际劳动节放假安排的通知 — 从5月6日起 "教师、学生上午上课时间不变，下午上课时间为14:30，后续上课时间顺延".
   https://www.nuc.edu.cn/info/1014/34650.htm
3. 中北大学关于2025年国庆节、中秋节放假安排的通知 — 从10月9日起 "下午上课时间为14:00，后续上课时间顺延".
   http://www.nuc.edu.cn/info/1014/39073.htm
4. 体育学院, 大学体育选课通知 (2015) — 第一大节 8:00-9:30, 第二大节 10:10-11:40, 第三大节 冬令时 2:00-3:30 / 夏令时 2:30-4:00 (PE runs 90-min blocks; consistent with the above).
   https://tyxy.nuc.edu.cn/info/1050/3013.htm
5. 教务部, 关于核对2025/2026学年第一学期课表的通知 — confirms 1–8 day periods and 9–11 evening periods exist (no clock times).
   https://jwc.nuc.edu.cn/info/1087/10663.htm

The exact switch dates move a day or two each year with the holiday notices; the game uses 5月6日 / 10月9日.
